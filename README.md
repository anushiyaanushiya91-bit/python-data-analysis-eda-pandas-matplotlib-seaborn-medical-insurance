# python-data-analysis-eda-pandas-matplotlib-seaborn-medical-insurance
InsureScope: Medical Insurance Cost Analysis

Project Overview

InsureScope is a data analytics project focused on analyzing medical insurance costs and identifying the key factors influencing insurance charges.

The project uses the Medical Cost Personal Dataset to explore relationships between demographic and lifestyle factors and medical insurance expenses.

Objectives

- Analyze medical insurance charges.
- Identify major cost-driving factors.
- Understand the impact of smoking, age, BMI, and other variables.
- Create meaningful visualizations and insights.

Dataset Description

The dataset contains 1,338 records and 7 columns.

- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Charges

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Power BI

Project Workflow

1. Raw Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Key Insights Identification
6. Power BI Dashboard Development

Key Analysis Areas

- Age vs Insurance Charges
- BMI vs Insurance Charges
- Smoking Status vs Insurance Charges
- Gender-wise Insurance Cost Analysis
- Region-wise Insurance Cost Analysis

Key Findings

- Smoking status is an important factor influencing insurance charges.
- Age and BMI are analyzed to understand their relationship with insurance expenses.
- Regional and demographic differences are explored.

Project Outcome

This project demonstrates practical data analytics skills, including data cleaning, exploratory data analysis, visualization, and business insight generation.
